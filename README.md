# 100년 · 우리들의 인생 기록장

같은 마을에서 각자의 선택으로 살아가는 교실용 도트 게임입니다. 교사가 방을 열면 학생 최대 20명이 별명과 캐릭터의 성별, 모습을 고르고 참가합니다.

## 바로 실행하기

Node.js 22 이상을 설치하고 저장소 폴더에서 실행합니다.

```sh
npm start
```

브라우저에서 [localhost:3000](http://localhost:3000)을 엽니다. 혼자 체험은 연습용 친구 세 명과 한 해씩 진행합니다. 실제 교실에서는 교사가 방을 만들고 **초대 QR**을 띄우거나 참가 링크와 6자리 코드를 알려 주세요. 한 PC에서 확인할 때는 교사 창과 학생 창을 각각 열면 됩니다.

## 게임 시작 후에도 참가하기

**진행 중인 게임에도 학생이 언제든 방 코드나 QR 링크로 참가할 수 있습니다.** 새로 참가한 학생은 기존 학생과 무관하게 0살부터 시작합니다. **각자 진행** 모드에서는 새 학생만 1년차부터 독립적으로 진행하고, **교사 마감·자동 진행** 모드에서는 현재 진행 중인 학급의 해에 합류하여 그 시점부터 인생 선택을 시작합니다. 앞서 지나간 학급 연도나 선택 결과는 소급 적용되지 않습니다. 새로고침이나 재접속은 기존 참가 세션으로 이어할 수 있습니다.

진행 중에도 정원 **20명**과 중복 별명 제한은 유지됩니다. 자동 진행 중에는 **이미 마감 시간이 지난 해를 정리한 뒤** 새 학생을 참가시켜 기존 학생의 선택이 되돌아가지 않도록 합니다. 새 학생이 들어와도 이미 진행 중인 학생들의 나이와 기록은 유지됩니다. **게임 전체 마감 후**에는 참가할 수 없고, 교사가 방을 초기화한 뒤에만 새로 들어올 수 있습니다.

## 중복 참가자 퇴장시키기

교사는 대기실과 **게임 진행 중**의 교사 진행실 학생 명단에서 각 학생 옆 **퇴장** 버튼을 누를 수 있습니다. 진행 중에는 **친구들** 탭에서도 학생을 퇴장시킬 수 있습니다. 이름과 나이를 확인하는 확인창에서 최종 승인하면 **선택한 학생 한 명의 접속 토큰·인생·선택 기록·순위 정보**가 삭제됩니다. 다른 학생들의 기록과 방 코드·설정은 유지됩니다.

퇴장한 학생의 기존 접속은 즉시 무효가 되지만, 같은 방 코드로 **신규 참가하면 0살부터 다시 시작할 수 있습니다.** 삭제된 인생 기록은 되찾을 수 없으므로 중복 참가자를 내보낼 때 남길 계정을 먼저 확인하세요. 자동 진행에서는 미제출 참가자를 내보내 남은 참가자가 모두 제출한 상태가 되면 다음 해로 넘어갑니다. 일시정지 중이라면 게임은 계속 멈춰 있습니다. 전체 게임 마감 후에는 개별 퇴장 대신 방 초기화를 사용할 수 있습니다.

## 수업 진행

1. **일상 선택을 누르면 바로 한 살** 자랍니다. 새 멀티 방에서는 친구마다 다른 나이에 각자의 이야기를 이어갈 수 있습니다.
2. 장래희망, 진학, 입영, 치료는 **같은 나이의 추가 선택**입니다. 고른 뒤 그해의 일상을 선택합니다. 교사는 수업 중 전체를 잠시 멈추고 다시 시작할 수 있습니다.
3. 초·중·고에서 고른 장래희망, 학교생활, 전공과 능력치가 취업에 이어집니다. 취업 카드에는 학력과 능력치 조건, 시작 비용, 한 해 수입과 피로가 표시됩니다. 운동부 훈련을 쌓으면 운동선수, 간호학과와 면허 시험을 마치면 간호사, 돌봄 교육과 시험을 마치면 요양보호사에 지원할 수 있습니다.
4. 능력치는 1점부터 쌓을 수 있습니다. 큰 병의 치료가 늦어지면 위험이 쌓입니다. 노년에 위중한 병이 생기면 집중 치료나 수술이 중요합니다. 성인이 되면 월세, 전세, 내 집 마련과 이사도 만납니다.
5. 삶을 마치면 다음 세대의 0살부터 이어가거나 영혼으로 머뭅니다. 다음 세대는 기본 능력치에 앞 세대의 자금과 관계 일부를 보너스로 받습니다. 영혼은 가족의 꿈, 장례식장, 예전 일터처럼 기억이 남은 곳을 한 번씩 방문할 수 있습니다.
6. 친구 메뉴에서 가계의 세대별 기록을 읽습니다. 순위에는 현재 나이와 직업이 나오며, 점수는 분야별로 현재 세대와 앞 세대의 최고 기록을 비교합니다. 교사가 **전체 게임 마감**을 눌러 수업을 마칩니다. 마감 후 교사 진행실에서 **방 초기화 · 새 게임 준비**를 누르고 방 코드를 입력하면 같은 6자리 코드와 교사 비밀번호, 기존 진행 설정을 유지한 채 빈 대기실로 돌아갑니다. 이전 학생들의 참가 정보·인생·선택 기록·순위는 삭제되며 복원할 수 없습니다. 기존 학생들은 다시 참가해야 하고 교사는 진행실을 계속 사용할 수 있습니다. 게임 진행 중에는 초기화할 수 없습니다.

선택 카드에는 바로 바뀌는 수치와 **매년** 바뀌는 수치를 따로 표시합니다. 일상 선택의 매년 효과는 다음 해부터, 추가 선택의 효과는 올해부터 적용합니다. 운동, 배움, 바쁜 일처럼 3년 동안 이어지는 활동은 새 활동을 시작하면 교체됩니다. **올해 변화**를 펼치면 수입, 월세, 돌봄 등을 확인할 수 있습니다. 결혼한 뒤에 아이를 맞이하는 선택이 열리며, 배우자와 아이가 마을 그림에 함께 나타납니다.

진학 화면에서는 **대학 진학**과 **대학원·직업훈련**을 따로 펼쳐 봅니다. 대학 학비에는 가족 지원이 적용되어 전공별 본인 부담이 최대 1~4코인이며, 남은 자금이 적으면 부담이 더 줄어듭니다.

선택하면 화면 아래에 캐릭터의 이야기가 나오고, 능력치가 바뀌면 바뀐 칸과 증감 수치가 잠깐 강조됩니다.

**메뉴**에서 플레이 팁과 직업별 설명, 취업 조건, 기본 연봉과 직업별 **연봉 성장 유형·정년**을 볼 수 있습니다. 연봉에는 경력, 직무에 맞는 능력치, 관련 대학원 수료가 반영됩니다. 관련 분야로 이직하면 다른 직장에서 쌓은 근속 경력의 절반을 최대 10년까지 인정합니다.

### 직업별 성장과 정년

| 유형 | 경력 증가 시점 / 증가액 | 예시 |
| --- | --- | --- |
| 초기 성장 | 2·5·10년 / +1씩 | 매장 직원, 식당 직원 |
| 안정 성장 | 4·9·16년 / +1씩 | 회사원, 공무원, 교사 |
| 숙련 성장 | 3·7·12·18년 / +1씩 | 생산직, 현장 기술자, 개발자 |
| 전문 성장 | 4·9·15년 / +1씩 | 연구원, 간호사, 의사 |
| 성과 성장 | 3·7·12년 / +1씩 + 별도 성과 보너스 | 창작자, 가게 주인, 방문판매원 |
| 선수 성장 | 2·4·7년 / +2씩 | 운동선수 |

직업마다 정년이 다릅니다. 선수는 38세에 은퇴하거나 필요한 능력치를 갖췄다면 운동 지도자로 전직할 수 있습니다. 육체노동이 많은 일부 직업은 60세, 일반 직업은 65세, 일부 전문·자영업은 68세에 정년을 맞습니다. 정년을 맞으면 기존 직장 일을 계속하는 선택지는 나오지 않습니다. 생산직의 기본 체력 소모는 매년 2에서 1로 줄이고 가게 주인 창업비는 38에서 24코인으로 완화했습니다.

### 직업 승진·전직

직업 선택 기회가 다시 열리면 현재 직업의 **승진·전직 기회가 먼저 표시**되고, 다른 직업은 접어 둔 **다른 직업 보기**에서 찾을 수 있습니다. 교사→교감→교장, 의사→임상교수→병원장, 간호사→책임간호사→수간호사→간호부장 등 **41개 활성 승진 단계**가 있습니다. 현재 직업에서 일정 연수 이상 근무하고 배움·관계·체력·예술·자금 등의 조건을 만족해야 지원할 수 있습니다. 일부 상위 직급은 관련 대학원 수료도 필요합니다.

승진 시에는 직전 직급뿐 아니라 그 이전 승진 단계의 경력까지 전부 연봉 상승에 반영합니다. 승진 직위는 일반 신규 취업 목록에서 직접 선택할 수 없습니다. 이름과 조건은 실제 직업 경로를 참고한 **교육용 게임의 간략화된 규칙**이며, 법적 승진 자격·특정 직장 채용 기준을 그대로 구현한 것은 아닙니다.

### 플레이 중 승진·전직 목표 확인

승진 단계가 있는 직업에 취업하면 **플레이 화면의 이야기 제목 아래**에 **승진·전직 준비** 패널이 나타납니다. 다음 목표 직급과 `2/3 충족`처럼 준비 현황을 보여주고, 펼치면 근속 연수·배움·관계·체력 등 직급별 조건의 현재 수치와 필요 수치, 충족/미충족 여부를 확인할 수 있습니다. 관련 대학원 수료가 필요한 직급에는 수료 여부도 표시합니다. 승진하여 직업이 바뀌면 새 직급의 다음 목표로 자동 갱신됩니다.

운동선수는 지도자 전직을 위한 경력·체력·관계 조건을 볼 수 있습니다. 승진 단계가 없는 성과형 직업이나 최종 직위, 은퇴 후에는 패널을 숨깁니다. 조건을 모두 채우더라도 **직업 선택 기회 또는 해당 전직 이벤트가 열려야** 실제 승진·전직을 선택할 수 있습니다. 진행 현황은 캐릭터의 저장된 경력·능력치에서 매번 계산되므로 별도의 저장 데이터나 추가 비용은 발생하지 않습니다.

### 성과형 직업의 매년 보너스

모든 직업에 승진 경로를 강제로 부여하지 않습니다. **농부, 창작자, 방문판매원, 영상 크리에이터, 가게 주인**은 기존 직업을 유지하면서 매년 수확·작품 판매·판매 실적·광고/후원·가게 매출에 따른 성과 보너스를 받습니다. **운동선수**는 경기 성적에 따른 상금을 받으며, 은퇴 시 운동 지도자로 전직하는 경로는 유지됩니다.

성과 보너스는 각각 **0~5코인**(농부·창작자·방문판매원·운동선수), **0~6코인**(크리에이터·가게 주인)이며 매년 **약 25% 확률로 0코인**입니다. 좋은 해에는 보너스가 생기고, 주요 능력치가 충분하거나 경력이 8년 이상이면 보너스가 커질 수 있습니다. 같은 참여자·나이·직업·능력치 상태에서는 새로고침해도 보너스가 다시 뽑히지 않습니다. 직업의 고정 연봉과 성과 보너스는 따로 합산되고, 보너스는 기본 연봉 인상이나 적금 증액 알림으로 취급하지 않습니다.

성과형 직업의 경력 연봉 보너스는 기존 **3·7·12년차 +2씩**에서 **+1씩**으로 낮춰, 새 성과 수입으로 소득이 과하게 증가하는 것을 막았습니다. 승진 단계를 제거한 이전 직위 10개(농장 운영자, 창작 감독, 영업팀장 등)는 **기존 저장 기록 호환을 위해 내부에만 유지**하며 신규 승진 또는 직업 안내에서는 보이지 않습니다. 이미 그 직위를 보유한 캐릭터는 계속 일할 수 있습니다.

### 연애와 결혼

24세부터 찾아오는 연애 이벤트에서는 상대의 이름, 나이, 직업을 간단히 확인할 수 있습니다. 상대는 반드시 성인이며 플레이어와 나이가 비슷합니다. 연애를 시작하면 별도 능력치 **애정(0~100)**이 표시됩니다. 연애 중에는 매년 여행(-5코인·애정 +12), 맛집(-2코인·애정 +7), 산책(무료·애정 +4), 혼자 쉬기(애정 -5) 중 하나를 추가로 고릅니다. 애정이 부족하면 결혼이 어려워지고, 크게 떨어지면 관계를 돌아볼 선택지가 생깁니다.

결혼에는 20코인이 들고 애정 65점 이상이 필요합니다. 결혼 후에는 상대의 직업과 나이에 맞는 가계 기여 소득이 들어오지만 두 사람이 함께 쓰는 추가 생활비(-2코인/년)도 발생합니다. 배우자도 나이를 먹고 은퇴하면 기여 소득이 줄어듭니다. 이름·직업·애정 정보는 저장된 인생 기록과 함께 유지됩니다.

### 직장생활 중 노후 저축

처음 취업하고 1~3년 내에 **저금하지 않기 / 매년 1·2·4코인 저금** 중 하나를 추가 선택으로 고릅니다. 이후 **연봉이 오를 때마다** 다음 해에 적금 선택이 다시 나타납니다. 저축하지 않았다면 새로 가입할 수 있고, 이미 가입했다면 기존 금액 유지 또는 연간 납입액 +1·+2·+4코인 증액 중에서 선택합니다. 기존 적립금은 어떤 선택을 해도 그대로 유지됩니다.

실제로 납부한 돈만 따로 적립하며, 기존 잔액에는 매년 **연 4% 복리 이자**가 붙습니다. **이자와 적립금은 정수 코인만 사용**하여, 이자가 1코인 미만이면 버립니다. 예를 들어 기존 적립액 100코인, 올해 납입액 4코인이면 다음 적립액은 108코인입니다. 돈이 부족한 해에는 낼 수 있는 금액만 적립합니다. 복무 중에는 납부하지 않고 이자는 계속 붙지만, 은퇴 후에는 적립·이자 계산을 중단합니다.

은퇴 후 적립금을 **일시금(25% 세금)** 또는 **10년 분할 연금(5% 세금)** 중 하나로 수령할 수 있습니다. 일시금은 선택 즉시 지급되며, 연금은 수령 선택 연도부터 매년 10회 지급됩니다. 모두 정수 코인만 사용합니다. 예를 들어 적립금이 100코인이면 일시금은 75코인, 연금은 세금 5코인을 뺀 95코인을 **첫 5년간 10코인씩, 나머지 5년간 9코인씩** 지급합니다. 세금 계산 후 발생한 1코인 미만 금액은 내림 처리합니다. 기본 은퇴 수입 1코인은 유지합니다.

50세부터 연령별 생활비가 추가로 발생합니다(50~64세 -1/년, 65~74세 -2/년, 75~84세 -3/년, 85세 이상 -4/년). 내 집을 소유하고 있다면 55세부터 집 관리비 -1코인/년, 75세부터 -2코인/년이 추가됩니다. 52·62·72·80·88세에는 건강 관리나 주거 환경에 돈을 쓸 수 있는 추가적인 일상 선택이 나옵니다. 이 생활비는 기존 월세·양육비와 별도로 계산됩니다.

게임 속 복무는 스무 살부터 일정을 고르고 스물여덟 살까지 시작합니다. 체력 40점 이하일 때 마을 복무, 20점 이하일 때 면제 선택이 열립니다. 2년의 복무를 마치면 하던 공부나 일을 이어갑니다. 태블릿이나 넓은 휴대폰을 가로로 두면 마을 그림과 능력치 옆에 선택지가 보입니다.

## 배포 방법 고르기

| 방식 | 준비 | 기록 보관 |
| --- | --- | --- |
| 교실 내부망 | 교사 PC에서 `npm start`를 실행하고 학생에게 `http://교사PC의내부IP:3000`을 공유합니다. 교사 화면도 이 주소로 열어야 초대 링크가 학생에게 열립니다. 같은 네트워크에서 기기 간 연결과 3000 포트가 허용돼야 합니다. | 교사 PC의 `data/` 폴더 |
| Railway | 저장소를 연결해 Node 서비스로 실행합니다. 시작 명령은 `npm start`, 헬스 체크는 `/api/health`입니다. 서비스에 공개 도메인을 만들고 `/data`에 볼륨을 붙인 뒤 `DATA_DIR=/data`를 설정합니다. [Railway 볼륨 안내](https://docs.railway.com/volumes/reference) | 붙인 볼륨에 보관 |
| Vercel | 저장소를 가져오고 아래의 Neon을 연결합니다. | 연결한 Neon PostgreSQL에 보관 |
| Render | 저장소를 **Web Service**에 연결합니다. Build Command는 `npm install`, Start Command는 `npm start`입니다. Node 22 이상을 사용합니다. 수업 기록 보관이 필요하면 유료 디스크를 `/var/data`에 마운트하고 `DATA_DIR=/var/data`를 설정합니다. [Render 무료 서비스 안내](https://render.com/docs/free) | 무료 테스트에서는 재시작·절전 시 기록이 초기화됨 |
| 학교 서버 또는 VPS | Node 22 이상으로 한 프로세스를 실행하고, 외부 공개 시 HTTPS 역방향 프록시를 연결합니다. | 서버의 지정 폴더 |

이 앱은 Node 서버가 방과 선택을 관리합니다. GitHub Pages는 정적 호스팅입니다. [GitHub Pages 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

### Vercel 설정

1. Vercel에서 이 저장소를 프로젝트로 가져옵니다. `vercel.json`이 화면과 게임 API를 배포합니다.
2. 프로젝트의 **Storage**에서 **Neon**을 연결합니다. 새 데이터베이스는 **Free**에서 선택 가능한 리전에 만들고 **Production**에 연결합니다. Vercel 프로젝트의 Functions 리전은 데이터베이스와 가까운 곳을 선택합니다. [Neon 연동 안내](https://vercel.com/marketplace/neon)
3. 다시 배포한 뒤 공개 주소의 `/api/health`에서 `{"status":"ok"}`를 확인합니다. 앱은 전용 방 테이블을 자동으로 만듭니다.
4. 교사는 **교사 방 만들기**에서 방마다 4~32자의 비밀번호를 정합니다. 학생은 받은 링크나 코드로 접속해 별명을 정합니다. 다른 기기에서 교사 진행실을 열 때는 **코드로 교사 방 열기**를 사용합니다. 이전 버전에서 만든 방은 기존에 저장한 교사 세션으로 이어 엽니다.

Vercel 버전은 여러 기기에서 같은 방을 열어도 각 학생의 선택을 한 건씩 순서대로 저장합니다.

## 운영 설정

| 환경 변수 | 기본값 | 용도 |
| --- | --- | --- |
| `PORT` | `3000` | HTTP 포트 |
| `DATA_DIR` | `./data` | 방 상태와 인생 기록을 저장할 경로 |
| `HOST_PIN` | 빈 값 | 자체 Node 서버에서 선택적으로 거는 방 열기 암호 |
| `DATABASE_URL` | 빈 값 | Vercel에서 사용할 PostgreSQL 연결 주소. Neon 연동 시 자동 설정 |

- 학생은 코드와 별명을 사용합니다. 새로고침이나 같은 브라우저의 이어 하기로 기존 캐릭터에 다시 들어갈 수 있습니다.
- 방 상태는 선택을 받을 때마다 저장됩니다. Node 서버는 로컬 파일, Vercel은 연결한 데이터베이스에 저장합니다. 상태가 바뀌지 않고 7일이 지난 방은 정리 대상입니다.
- 배포 플랫폼에서 인스턴스를 하나로 유지하고 영구 저장소를 연결하면 프로세스 재시작 후에도 방을 다시 열 수 있습니다.
- 게임 진행은 `public/game.mjs`, 연령별 이야기와 일상은 `public/life.mjs`와 `public/content.mjs`, 치료 선택은 `public/health.mjs`에 있습니다.
